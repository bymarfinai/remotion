# Style 002 — Reference Breakdown (frame-by-frame)

Status: **source-of-truth analysis for the next rebuild**.

The previous EIM v1–v4 experiments were too infographic-heavy and reused KEC assets that do not belong to this visual language. Do not use those versions as the quality baseline.

## What the reference actually is

A **minimal editorial kinetic explainer** built around a persistent rounded white/ivory card, monochrome navy/blue visual metaphors, sparse typography, and one dominant idea per beat.

It is not a dense infographic layout and it is not a collage style.

## Persistent frame language

- bright white / warm-white card,
- thin navy rounded border,
- soft drop shadow,
- generous empty space,
- faint low-contrast decorative line art / ghosted illustrations in the background,
- dark navy + medium blue as the dominant palette,
- almost no texture,
- no distressed collage treatment,
- no orange,
- no torn paper,
- no photographic skyline collage.

## Typography behavior

- small sentence setup in regular / medium weight,
- one key word or short phrase becomes large, bold, uppercase,
- text blocks remain short,
- text is positioned with deliberate empty space around it,
- emphasis is created through scale and timing, not through many labels/cards.

Typical reference pattern:

small setup sentence
**BIG KEYWORD**

or

small phrase
**IMPORTANT CONCEPT**

## Asset language

The reference repeatedly uses a **single monochrome sculptural / 3D metaphor object** as the focal image.

Observed focal assets include:
- hourglass,
- classical bust/head with visible brain,
- seated thinker figure,
- monochrome crowd / audience,
- very simple scissors / music / sound / timing icons.

These are clean, isolated, navy/blue-tinted assets. They are not textured collage cutouts.

## Motion grammar

- object slides or scales in smoothly,
- short text appears phrase-by-phrase,
- focal object often sits inside or intersects a simple circular field,
- the composition frequently clears almost completely before the next beat,
- a thin curved line becomes a narrative path,
- small icons appear sequentially along the path,
- block rows build one segment at a time,
- transitions are clean and controlled,
- no aggressive bounce,
- no kinetic-collage jitter,
- no camera-heavy treatment.

## Sequence logic observed

The reference is structured as successive micro-scenes:

1. question + hourglass,
2. brain / memory metaphor,
3. thinker / feeling metaphor,
4. segmented blocks explaining editing,
5. curved path with tools/icons,
6. circular memorable payoff,
7. blocks again for a concluding statement,
8. crowd + brain for the final emotional payoff.

Each beat is visually sparse.

## Critical rules for the next rebuild

1. Do **not** reuse KEC collage assets (skyline, birds, torn paper, distressed texture).
2. Build a dedicated Style 002 asset pack.
3. Use monochrome navy/blue focal objects.
4. Keep one dominant object per beat.
5. Preserve very large areas of white/ivory negative space.
6. Use only minimal diagram devices at any one time.
7. Use the curved path as one dedicated beat, not a permanent background device.
8. Let scenes clear before the next idea arrives.
9. Use 7 seconds for the next test so the rhythm can breathe.
10. Ship new local binary assets as a ZIP + install.ps1.

## V5 target

The next candidate should be a **full reset**, not a tweak of V4.

Working target:
- 1080x1920,
- 30 fps,
- 7 seconds / 210 frames,
- dedicated Style 002 asset pack,
- 4–5 sparse micro-scenes,
- no KEC visual residue.

Do not lock Style 002 until this reset version is visually approved.
