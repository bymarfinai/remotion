# Marfin Motion Style Catalog

This folder is the Remotion-side style catalog.

A **style** is not a finished template. It is a reusable creative-direction and motion-grammar definition that generated videos can target.

## Current styles

### 001 — Kinetic Editorial Collage (KEC)

Category: Editorial Collage

Core language:
- photographic/generated cutouts,
- paper and print texture,
- oversized editorial typography,
- geometric accents,
- fast staggered entrances,
- overshoot and small rotational settles,
- subtle camera push.

## User workflow

The user does not need to provide visual assets.

Example brief:

`Bikin video 5 detik style KEC tentang Monas`

The AI director is responsible for concept, storyboard, asset planning, asset generation, Remotion composition, and render preview. The user only approves or requests revisions.

The files in this catalog exist so Remotion and the AI director refer to the same named style vocabulary.
