# Marfin Motion Style Catalog

This folder is the Remotion-side style catalog.

A **style** is not a finished template. It is a reusable creative-direction and motion-grammar definition that generated videos can target.

## Current styles

### 001 — Kinetic Editorial Collage (KEC)

Category: Editorial Collage

Core language:
- photographic/generated cutouts,
- paper and print texture,
- oversized editorial typography,
- geometric accents,
- fast staggered entrances,
- overshoot and small rotational settles,
- subtle camera push.

## User workflow

The user does not need to provide visual assets.

Example brief:

`Bikin video 5 detik style KEC tentang Monas`

The AI director is responsible for concept, storyboard, asset planning, asset generation, Remotion composition, and render preview. The user only approves or requests revisions.

The files in this catalog exist so Remotion and the AI director refer to the same named style vocabulary.


### KEC production baseline

The approved default quality bar is now standardized:

- real/generated hero cutout,
- real/generated contextual collage imagery,
- distressed charcoal/paper background rather than flat black,
- native Remotion typography and simple graphic shapes,
- warm-ivory paper labels / torn strips,
- cobalt + orange graphic masses by default when no brand palette is supplied,
- independently animated layers,
- no full-poster raster fallback,
- no placeholder substitution for required generated imagery,
- verify all assets visibly render before calling the composition complete.

After the user approves the concept, proceed directly to asset generation + Remotion build instead of asking for another production-plan approval.


### ZIP delivery

For KEC builds that require generated binary assets in the local Remotion repo, deliver a downloadable ZIP with the assets and an `install.ps1` helper. This is part of the standard workflow.
